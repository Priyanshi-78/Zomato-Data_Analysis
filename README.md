# Zomato Data Analysis | Python & EDA

## Project Overview
An exploratory data analysis project focused on analyzing Zomato restaurant data to uncover insights into restaurant trends, customer preferences, ratings, and pricing patterns.

The objective is to transform raw restaurant data into meaningful insights through data analysis and visualization.

## Objectives
- Analyze restaurant ratings and customer preferences.
- Explore restaurant distribution across locations.
- Examine pricing trends and cost variations.
- Identify popular cuisines and restaurant categories.
- Understand factors influencing restaurant ratings.

## Tech Stack
- **Python** – Data Analysis
- **Pandas** – Data Manipulation
- **NumPy** – Numerical Computing
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Visualization
- **Jupyter Notebook** – Development Environment

## Project Workflow
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Insights & Interpretation
